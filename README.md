# Modelo de e-mail | Wikimedia Brasil

Modelo de e-mail pronto, com cabeçalho e texto, para copiar e colar no Gmail.

## Para quem vai usar

1. Abra a página do modelo: **https://garbezeando.github.io/email-wmb/modelo-email.html**
2. Clique em **Copiar e-mail**.
3. No Gmail, clique em **Escrever** e cole (Ctrl+V) no corpo da mensagem.
4. Confira se o cabeçalho apareceu, edite o que precisar e envie.

**Dicas**
- Faça pelo computador. No celular a cópia pode falhar.
- Se o botão não copiar, selecione o e-mail com o mouse e use Ctrl+C.
- Se a imagem sair com tamanho estranho, clique nela e escolha **Tamanho original**.
- Envie um teste para você mesmo antes de mandar de verdade.
- Mantenha `width="600"` e `max-width:600px` na imagem. É o que garante o tamanho certo no PC e no celular.
